# training-facility
The place where the source files for the game "Training Facility" live.

As seen elsewhere, this is the main repository for the aforementioned game.

## FAQ

### "Is this free?"
> Yes. You are free to download the source code and play the game, or modify it and redistribute.

### "Where can I play this?"
> You can either play it on itch.io or download the source and run it directly on your machine. Linked [here.](https://stargost.itch.io/training-facility)
> If you find the game anywhere else, chances are they just grabbed my thingamabob and redistributed it.

### "Which engine is this made in?"
> Godot 4.

### "Your code sucks!"
> I am aware. Feel free to contribute if you have nothing better to do.

### "Did you use AI for this?"
> Nope.

### "Why are there 2 licenses?"
> The code itself is licensed under CC-BY-NC 4.0, but I still reserve all rights for the assets, logo, and name of the game.
> Exceptions apply to some assets which are under other licenses, since I borrowed a few from OpenGameArt. You may see the credits section of the game to know which ones I borrowed.
> This may be unnecessary, but I am no lawyer and I don't have that much knowledge of copyright law, so better be safe than sorry.
